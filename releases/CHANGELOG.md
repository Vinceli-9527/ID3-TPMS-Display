# 变更记录

## v0.5.0 — 2026-11-20

触摸绑定轮位与分页键盘打通的公开版本（归档于 releases/v0.5.0）。

- **触摸支持**：CST816D（I2C 0x15，写 0xFE=0x01 关自动休眠），点按 + 左右滑动识别
- **轮位绑定**：点轮位 → 候选列表点选 ID（最近 30 秒内、最多 3 个）/ 手动键盘输入
- **分页键盘**：4 页 × 4 大键 = 16 个十六进制字符，滑动换页，DEL/OK，6 位 ID
- **掉电保存**：绑定写入 NVS（命名空间 tpms3），重启不丢
- **界面重做**：车模俯视位图（tools/img2rgb565.py 生成 40×74 RGB565）、绿色虚线引导线、
  外环 4px、数值透明底不遮引导线、温度手绘度数符号
- 修复：早期每 500 ms 整屏重绘造成的闪烁 → 静态/数值/状态三层局部刷新
- 固件：releases/v0.5.0/id3-tpms-ui-v0.5.0.bin（1,055,232 B，Flash 77%）
- 新增工具：tools/img2rgb565.py（图片 → RGB565 C 数组）

### 说明
0.2.0 ~ 0.4.0 为本地迭代版本，未单独归档。主要阶段为：触摸芯片验证（touch-probe/）→
页面状态机与绑定数据结构 → 分页键盘与掉电保存 → 0.5.0 整合发布。

### 未完成
- 高压段（b[10]==1）实测验证
- 电压常量与参考读数交叉验证

## v0.1.0 — 2026-11-18

首个可用版本（归档于 releases/v0.1.0）。

- 通信格式：本项目通过实测抓取广播帧整理，并经与传感器读数比对验证
- 纯广播解析：adv 帧头 02 01 06 03 03 B0 FB，19 字节载荷
- 压力 3.144 kPa/LSB、温度 b[6]-55、电压 b[4]*0.01+1.22、ID = b[18]b[17]b[16]
- 圆屏四轮显示、低压变色、数据时效、状态灯
- 局部刷新，消除整屏闪烁
- 固件：releases/v0.1.0/id3-tpms-ui-v0.1.0.bin

### 未完成
- 轮位（左前/右前/左后/右后）绑定
- 高压段（b[10]==1）实测验证
- 电压常量与 App 比对

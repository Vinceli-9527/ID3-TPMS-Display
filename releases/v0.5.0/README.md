# ID.3 蓝牙胎压小屏 · v0.5.0 归档

**版本**：0.5.0
**归档日期**：2026-11-20
**状态**：可用（触摸绑定轮位 + 分页键盘 + 车模界面）

---

## 一、这一版能做什么

| 能力 | 说明 |
|---|---|
| 被动监听广播 | 识别 FF00 类胎压传感器（帧头 `02 01 06 03 03 B0 FB`），无需配对或连接 |
| 数据解析 | 压力 / 温度 / 电压 / 状态 / 传感器 ID |
| 四轮显示 | 车模俯视图居中，四角显示压力大字（size 4）+ 温度 + 单位 |
| 低压告警 | < 2.0 bar 红、< 2.2 bar 黄；10 分钟无更新变灰 |
| 状态灯 | 绿色常亮=正常，红色闪烁=无数据或告警 |
| **触摸绑定轮位** | 点轮位区域 → 从候选列表点选 ID，或点 `manual` 用键盘手输 |
| **分页键盘** | 4 页 × 4 大键 = 16 个十六进制字符，左右滑动换页，6 位 ID 输入 |
| 掉电保存 | 绑定关系写入 NVS（命名空间 `tpms3`），重启不丢 |
| 局部刷新 | 静态层 / 数值层 / 状态层分离，无整屏闪烁 |

## 二、屏幕布局

```
        ALL OK  ●              ← 状态 + 状态灯（唯一会闪的区域）
  LF 22  2.6bar        2.5bar  RF 25
          °C                 °C      ← 压力 size4 + 温度
              ┌────┐
              │车模│                ← 40×74 俯视图（car_img.h）
              └────┘
            LF   RF  ← 绿色虚线引导
            LR   RR
              ID.3
              3s                ← 数据时效
```

## 三、通信格式（本项目实测整理）

| 字段 | 换算 |
|---|---|
| 电压 | `b[4] * 0.01 + 1.22` V |
| 压力 | `b[5] * 3.144` kPa；若 `b[10] == 1` → `(b[5] + 256) * 3.144` |
| 温度 | `b[6] - 55` ℃ |
| 状态 | `b[7]` |
| 传感器 ID | `b[18] b[17] b[16]`（与传感器背面印字一致） |
| 设备地址 | `<ID 三字节> : 11:11:11` |

## 四、硬件与编译

| 项 | 值 |
|---|---|
| 开发板 | ESP32-2424S012（ESP32-C3 + GC9A01 240×240 + CST816D 触摸） |
| LCD | SCLK=6 MOSI=7 DC=2 CS=10 RST=-1 BL=3（LEDC 通道必须 0~5） |
| 触摸 | SDA=4 SCL=5 RST=1，I2C 地址 0x15，需写 0xFE=0x01 关自动休眠 |
| 依赖库 | LovyanGFX 1.3.0 |
| FQBN | `esp32:esp32:esp32c3:CDCOnBoot=cdc` |
| 固件占用 | Flash 77%（1,009,920 B）/ RAM 10% |

### 烧录

```bash
arduino-cli upload -p <你的端口，如 COM5> --fqbn "esp32:esp32:esp32c3:CDCOnBoot=cdc" --input-dir . id3-tpms-ui-v0.5.0
```

本目录已含 `id3-tpms-ui-v0.5.0.bin` / `bootloader.bin` / `partitions.bin` / `car_img.h`。

## 五、使用要点

1. 传感器拧上气门嘴后，**松半圈再拧回**以唤醒；屏幕几秒内出现 ID 与气压
2. **绑定轮位**：点屏幕上某个轮位区域 → 出现候选列表（最近 30 秒出现过的最多 3 个）→ 点目标 ID
3. 候选里没有时：点 `manual` → 滑动翻页 → 输入 6 位 ID → `OK`
4. 同一 ID 绑到第二个轮位时，会**自动清除**原来那一格，避免重复
5. 长按 BOOT 可清空已识别数据（绑定关系保留）

## 六、已知限制

1. **高压段未验证** —— `b[10] == 1` 的高位分支尚未在 2.5 bar 以上实测确认
2. **电压常量未交叉验证** —— 换算值约 3.2 V，尚未与参考读数比对
3. 触摸无校准，个别机器边缘点选可能偏移
4. 未做外壳，供电依靠 USB 车充或充电宝

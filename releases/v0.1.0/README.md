# ID.3 蓝牙胎压小屏 · v0.1.0 归档

**版本**：0.1.0
**归档日期**：2026-11-18
**状态**：可用（被动监听广播，已用真实传感器验证压力/温度/ID）

---

## 一、这一版能做什么

- 被动监听蓝牙广播，识别 FF00 类胎压传感器（帧头 `02 01 06 03 03 B0 FB`）
- 解析 19 字节载荷，得到 **压力 / 温度 / 电压 / 状态 / 传感器 ID**
- 240×240 圆屏显示最多四个轮位：ID 尾号、压力（4 号大字）、温度
- 压力 < 2.0 bar 变红，< 2.2 bar 变黄，10 分钟无更新变灰
- 顶部状态灯：绿色常亮=正常，红色闪烁=无数据/告警
- 局部刷新（不整屏重绘，无闪烁）
- BOOT 键清空已识别传感器

## 二、通信格式（本项目实测整理）

### 广播帧结构

```
前 7 字节 = 02 01 06 03 03 B0 FB
载荷 = 广播包第 7 字节起，共 19 字节
```

### 载荷字段

| 字段 | 换算 |
|---|---|
| 电压 | `b[4] * 0.01 + 1.22` V |
| 压力 | `b[5] * 3.144` kPa；若 `b[10] == 1` → `(b[5] + 256) * 3.144` |
| 温度 | `b[6] - 55` ℃ |
| 状态 | `b[7]` |
| 传感器 ID | `b[18] b[17] b[16]`（与传感器背面印字一致） |

### ID 与设备地址的关系

```
设备地址 = <ID 三字节> : 11:11:11        // 后三字节为厂商固定值
例：ID 0631FB  →  06:31:FB:11:11:11
```

### 对照验证（真实数据）

| 帧 | b[5] | 换算 | 参考读数 | b[6] | 换算 | 参考读数 |
|---|---|---|---|---|---|---|
| 1 | 29 | 91.2 kPa | 0.91 bar ✅ | 80 | 25 ℃ | 25 ℃ ✅ |
| 2 | 22 | 69.2 kPa | 0.69 bar ✅ | 80 | 25 ℃ | 25 ℃ ✅ |
| 3 | 0 | — | 0.08 bar（个别字节待核） | 81 | 26 ℃ | 26 ℃ ✅ |

## 三、硬件与编译

| 项 | 值 |
|---|---|
| 开发板 | ESP32-2424S012（ESP32-C3 + GC9A01 240×240 + CST816D） |
| LCD | SCLK=6 MOSI=7 DC=2 CS=10 RST=-1 BL=3（LEDC 通道必须 0~5） |
| 触摸 | SDA=4 SCL=5 INT=0 RST=1（本版未使用） |
| 依赖库 | LovyanGFX 1.3.0 |
| FQBN | `esp32:esp32:esp32c3:CDCOnBoot=cdc` |
| 固件占用 | Flash 74%（975,948 B）/ RAM 10% |

### 烧录

```bash
arduino-cli upload -p <你的端口，如 COM5> --fqbn "esp32:esp32:esp32c3:CDCOnBoot=cdc" --input-dir . id3-tpms-ui-v0.1.0
```

目录内已含 `id3-tpms-ui-v0.1.0.bin` / `bootloader.bin` / `partitions.bin`。

## 五、已知限制

1. **轮位未做映射** —— 目前按 ID 字典序占四个角，尚未绑定左前/右前/左后/右后
2. **高压段未验证** —— `b[10] == 1` 的高位分支尚未在 2.5 bar 以上实测确认
3. **电压常量未交叉验证** —— 3.24 V 三帧一致，但尚未与参考读数比对
4. 触摸未使用；无 WiFi 上传、无蜂鸣器

## 六、版本要点

- 采用**被动监听广播**的工作方式，无需配对或建立连接
- 修复早期每 500 ms 整屏重绘导致的闪烁 → 改为分层局部刷新
- 外环固定紫色 `0x9400D3`，内圈 `0x4B0082`
- 状态心跳改为右上角小圆点（绿常亮/红闪）
- 数值字号 size 3 → size 4，并重排布局避免重叠

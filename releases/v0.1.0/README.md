# ID.3 蓝牙胎压小屏 · v0.1.0 归档

**版本**：0.1.0
**归档日期**：2026-11-18
**状态**：可用（纯广播解析，已用真实传感器验证压力/温度/ID）

---

## 一、这一版能做什么

- 被动扫描 BLE 广播，识别 FF00 类胎压传感器（帧头 `02 01 06 03 03 B0 FB`）
- 解析 19 字节载荷，得到 **压力 / 温度 / 电压 / 状态 / 传感器 ID**
- 240×240 圆屏显示最多四个轮位：ID 尾号、压力（4 号大字）、温度
- 压力 < 2.0 bar 变红，< 2.2 bar 变黄，10 分钟无更新变灰
- 顶部状态灯：绿色常亮=正常，红色闪烁=无数据/告警
- 局部刷新（不整屏重绘，无闪烁）
- BOOT 键清空已识别传感器

## 二、协议（来源：REA 反编译 LYTPMS 1.0.8.821）

### 广播识别

```
adv 前 7 字节 = 02 01 06 03 03 B0 FB
载荷 = adv[7 .. 7+19)
```

### 载荷解析（TireBean.parse）

| 字段 | 公式 |
|---|---|
| 电压 | `b[4] * 0.01 + 1.22` V |
| 压力 | `b[5] * 3.144` kPa；若 `b[10] == 1` → `(b[5] + 256) * 3.144` |
| 温度 | `b[6] - 55` ℃ |
| 状态 | `b[7]` |
| ID | `b[18] b[17] b[16]`（倒序，与传感器背部印字一致） |

### ID 与 MAC 的关系（实测确认）

```
MAC = <ID 三字节> : 11:11:11        // 后缀为厂商固定值
例：ID 0631FB  →  MAC 06:31:FB:11:11:11
```

### 对照验证（真实数据）

| 帧 | b[5] | 计算 | 屏幕 | b[6] | 计算 | 屏幕 |
|---|---|---|---|---|---|---|
| f12 | 29 | 91.2 kPa | 0.91 bar ✓ | 80 | 25℃ | 25C ✓ |
| f22 | 22 | 69.2 kPa | 0.69 bar ✓ | 80 | 25℃ | 25C ✓ |
| f57 | 0 | — | 0.08 bar（照片位误差待核） | 81 | 26℃ | 26C ✓ |

## 三、硬件与编译

| 项 | 值 |
|---|---|
| 开发板 | ESP32-2424S012（ESP32-C3 + GC9A01 240×240 + CST816D） |
| LCD | SCLK=6 MOSI=7 DC=2 CS=10 RST=-1 BL=3（LEDC 通道必须 0~5） |
| 触摸 | SDA=4 SCL=5 INT=0 RST=1（本版未使用） |
| 依赖库 | LovyanGFX 1.3.0 |

| 固件占用 | Flash 74%（975,948 B）/ RAM 10% |

### 烧录

```
arduino-cli upload -p COM5 --fqbn "esp32:esp32:esp32c3:CDCOnBoot=cdc" --input-dir <本目录> id3-tpms-ui-v0.1.0
```

目录内已含 `id3-tpms-ui-v0.1.0.bin` / `bootloader.bin` / `partitions.bin`。

## 五、已知限制（下一版处理）

1. **轮位未做映射** —— 目前按 ID 字典序占四个角，尚未绑定左前/右前/左后/右后
2. **高压段未验证** —— `b[10] == 1` 的高位分支尚未在 2.5 bar 以上实测确认
3. **电压常量未交叉验证** —— 3.24 V 三帧一致，但未与 App 显示比对
4. 触摸未使用；无 WiFi 上传、无蜂鸣器

## 六、变更要点（相对早期探针版本）

- 从"连接式读取"改为**纯广播解析**（反编译确认数据在 adv 内）

- 状态心跳改为右上角小圆点（绿常亮/红闪）
